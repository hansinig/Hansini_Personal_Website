hansini-portfolio
Personal portfolio for Hansini Gundavarapu — built with Next.js, TypeScript, Tailwind CSS, Framer Motion, GSAP, Lenis smooth scroll, and React Three Fiber.
Live site: https://didi-ivory.vercel.app
Stack

Next.js 14 App Router
TypeScript
Tailwind CSS
Framer Motion + GSAP ScrollTrigger
Lenis smooth scrolling
React Three Fiber (Three.js particle hero)

To run locally
npm install
npm run dev
To update content — edit src/data/portfolio.ts, everything pulls from there.
To deploy
git add . && git commit -m "update" && git push
Vercel auto-deploys on every push.
